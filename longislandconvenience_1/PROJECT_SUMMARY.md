## 🔧 Customization Examples

### Change Main Colors
Edit CSS variables in any HTML file:
```css
:root {
    --accent-gold: #d4af37;      /* Change gold accents */
    --accent-pink: #e94b7f;      /* Change pink accents */
    --primary-burgundy: #6b3e4a; /* Change brand color */
}
```

### Add Blog Post
Add to `blogPosts` array in blog.html:
```javascript
{
    id: 13,
    title: "Your Blog Title",
    excerpt: "Preview text...",
    category: "sports-cards",
    date: "09-Jun-2026",
    author: "Your Name",
    image: "./images/image.png",
    featured: false
}
```

### Update Store Information
Modify `stores` array in index.html:
```javascript
{
    name: "Store Name",
    category: "Category",
    description: "Description...",
    status: "LIVE",
    image: "./images/image.png",
    url: "#"
}
```

### Change Timer Date
Update `initializeTimer()` function:
```javascript
let target = new Date(2027, 0, 1); // New Year 2027
```
