## WORKFLOW WF-A: SOCIAL BLAST (Single-Click Multi-Platform)

**Purpose:** Receive one content package → post to ALL relevant social platforms in parallel  
**Trigger:** Webhook (called by WF-B, WF-C, WF-D, or manually)  
**Runtime:** ~30–60 seconds for all platforms  

### Input Payload (JSON)
```json
{
  "brand": "longislandconvenience",
  "content_type": "blog | product | video | image | promotion",
  "text": "Main caption text (under 280 chars for Twitter)",
  "text_long": "Full description for Facebook/LinkedIn (up to 2000 chars)",
  "image_url": "https://cdn.odoo.com/path/to/image.jpg",
  "video_url": "https://storage/path/to/video.mp4",
  "link_url": "https://longislandconvenience.com/blog/post-slug",
  "hashtags": ["LongIsland", "Plainview", "NassauCounty"],
  "platforms": ["facebook", "instagram", "tiktok", "pinterest", "twitter", "linkedin"],
  "schedule_time": null
}
```

### n8n Node Flow
```
[Webhook Trigger]
       |
[Set Variables Node]
  — brand config lookup (page IDs, account IDs)
  — format text per platform max length
  — append brand hashtags
       |
[Switch: content_type]
  — blog/image → image post branch
  — video → video post branch
       |
[Parallel Split — all at once]
   ├─[Facebook Post]──────────────────────────────────
   │   Node: HTTP Request
   │   Method: POST
   │   URL: https://graph.facebook.com/v19.0/{page-id}/photos
   │   Body: { message: text_long + hashtags, url: image_url }
   │   Auth: Bearer {facebook_page_token}
   │
   ├─[Instagram Post]──────────────────────────────────
   │   Step 1 — Create media container:
   │   POST https://graph.facebook.com/v19.0/{ig-user-id}/media
   │   { image_url, caption: text + hashtags }
   │   Step 2 — Publish container:
   │   POST https://graph.facebook.com/v19.0/{ig-user-id}/media_publish
   │   { creation_id: from_step_1 }
   │
   ├─[TikTok Post]──────────────────────────────────
   │   Node: HTTP Request
   │   URL: https://open.tiktokapis.com/v2/post/publish/video/init/
   │   Body: { post_info: { title, privacy_level: PUBLIC_TO_EVERYONE },
   │           source_info: { source: PULL_FROM_URL, video_url } }
   │   Auth: Bearer {tiktok_access_token}
   │
   ├─[Pinterest Pin]──────────────────────────────────
   │   Node: HTTP Request
   │   POST https://api.pinterest.com/v5/pins
   │   Body: { board_id, title, description, media: { images: {image_url} },
   │           link: link_url }
   │   Auth: Bearer {pinterest_token}
   │
   ├─[Twitter/X Post]──────────────────────────────────
   │   Node: HTTP Request
   │   POST https://api.twitter.com/2/tweets
   │   Body: { text: short_text + top_3_hashtags }
   │   Auth: OAuth 1.0a {twitter_credentials}
   │
   └─[LinkedIn Post (JHD + Print only)]──────────────
       Node: HTTP Request
       POST https://api.linkedin.com/v2/ugcPosts
       Body: { author: "urn:li:organization:{org-id}",
               lifecycleState: "PUBLISHED",
               specificContent: { shareCommentary: { text },
                                  shareMediaCategory: "IMAGE" } }
       Auth: Bearer {linkedin_token}
       |
[Merge All Results]
       |
[IF any_failed = true]
   ├─[YES] → [WhatsApp Alert to Team] (Twilio)
   │          "⚠️ Failed to post on: {failed_platforms}"
   └─[NO]  → [Log Success to Odoo Activity]
       |
[Odoo Log Node]
  HTTP POST to Odoo: create mail.activity with result summary
```

### Platform-Specific Formatting Rules (Set Variables Node)
```javascript
// n8n Function Node — Format per platform
const brand = $json.brand;
const baseText = $json.text;
const hashtags = $json.hashtags.map(h => `#${h}`).join(' ');

return {
  facebook_text:  $json.text_long + '\n\n' + hashtags,        // Max 63,206 chars
  instagram_text: baseText.substring(0, 2200) + '\n\n' + hashtags,  // Max 2,200
  twitter_text:   baseText.substring(0, 250) + ' ' + hashtags.split(' ').slice(0,3).join(' '), // Max 280
  linkedin_text:  $json.text_long + '\n\n' + hashtags,        // Max 3,000
  tiktok_title:   baseText.substring(0, 150),                  // Max 150
  pinterest_desc: $json.text_long.substring(0, 500) + ' ' + hashtags  // Max 500
};
```

## WORKFLOW WF-B: DAILY BLOG AUTO-GENERATION
### (longislandconvenience.com ONLY — Runs Every Morning 7 AM EST)

**Purpose:** Auto-write, publish, and share 1 blog post per day on LIC  
**Trigger:** n8n Cron — `0 7 * * *` (7:00 AM EST daily)  
**Output:** Published Odoo blog post + social posts via WF-A  
**Estimated run time:** 3–5 minutes  

### Step-by-Step Node Flow

```
[Cron Trigger: 7:00 AM daily]
       |
[Step 1 — Get Today's Context]
  Node: HTTP Request → SerpAPI Google Trends
  URL: https://serpapi.com/search?engine=google_trends&geo=US-NY
  Extract: top 5 trending topics for New York today
  Also fetch: upcoming holidays/events (next 7 days)
       |
[Step 2 — Check Recent Blog Posts (avoid duplicates)]
  Node: HTTP Request → Odoo XMLRPC
  Method: search_read on blog.post
  Filter: website_id=1, published in last 14 days
  Extract: list of recent titles/topics
       |
[Step 3 — Choose Today's Topic (Claude API)]
  Node: HTTP Request → Anthropic API
  Model: claude-sonnet-4-6
  System prompt:
    "You are a content strategist for Long Island Convenience,
     a store in Plainview NY with 7 brands. Choose ONE blog topic
     that is: (1) relevant to trending NY topics, (2) not in recent posts,
     (3) helpful for Nassau County residents, (4) naturally mentions
     our brands (cards, gift baskets, balloons, print, etc)."
  Input: trending_topics + recent_post_titles + today's date
  Output: { topic, title, angle, keywords[5], target_word_count: 900 }
       |
[Step 4 — Write Full Blog Article (Claude API)]
  Node: HTTP Request → Anthropic API
  Model: claude-sonnet-4-6
  Prompt template:
    "Write a {word_count}-word SEO blog article for longislandconvenience.com.
     Title: {title}
     Focus keywords: {keywords}
     Location: Plainview, NY / Nassau County / Long Island
     Tone: friendly, local, helpful
     Structure:
       - H1: {title}
       - Introduction (hook + location mention)
       - 3–4 H2 sections with practical content
       - Natural mentions of store services where relevant
       - CTA at end: visit us at 605 Old Country Road, Plainview NY
     Format: HTML (use <h2>, <p>, <strong>, <ul> tags)"
  Output: full HTML article body
       |
[Step 5 — Generate Featured Image (OpenAI DALL-E 3)]
  Node: HTTP Request → OpenAI API
  URL: https://api.openai.com/v1/images/generations
  Body: {
    model: "dall-e-3",
    prompt: "Bright, friendly photo-realistic image for a blog about {topic}.
             Long Island NY theme, warm colors, welcoming, no text overlays.
             Style: professional lifestyle photography",
    size: "1792x1024",
    quality: "standard",
    n: 1
  }
  Output: image_url (temporary OpenAI URL)
       |
[Step 6 — Download & Upload Image to Odoo]
  Node: HTTP Request (GET image from OpenAI URL) → binary data
  Then: HTTP Request → Odoo XMLRPC ir.attachment create
  { name: "{title}_featured.jpg",
    res_model: "blog.post", type: "binary",
    datas: base64(image_bytes) }
  Output: attachment_id, public_url
       |
[Step 7 — Create Blog Post in Odoo]
  Node: HTTP Request → Odoo XMLRPC
  Model: blog.post
  Method: create
  Data: {
    name: "{title}",
    blog_id: 1,          ← LIC main blog ID
    website_id: 1,
    subtitle: "{seo_description_150_chars}",
    author_id: 2,        ← Sachin/admin user
    cover_properties: '{"background-image":"url({image_url})"}',
    is_published: true,
    website_meta_title: "{title} | Long Island Convenience",
    website_meta_description: "{seo_description}",
    website_meta_keywords: "{keywords_csv}"
  }
  Then: write the HTML content to the blog post view arch
  Output: blog_post_id, public_url (/blog/post-slug)
       |
[Step 8 — Generate Social Caption (Claude API)]
  Node: HTTP Request → Anthropic API
  Prompt: "Write a social media caption for this blog post.
           Brand: Long Island Convenience, Plainview NY
           Blog title: {title}
           Blog link: {url}
           Give me: short_caption (under 280 chars), long_caption (under 500 chars),
           5 relevant hashtags including #LongIsland #PlainviewNY #NassauCounty"
  Output: short_caption, long_caption, hashtags[]
       |
[Step 9 — Trigger WF-A Social Blast]
  Node: HTTP Request → WF-A Webhook
  Body: {
    brand: "longislandconvenience",
    content_type: "blog",
    text: short_caption,
    text_long: long_caption,
    image_url: featured_image_url,
    link_url: blog_public_url,
    hashtags: ["LongIsland", "PlainviewNY", "NassauCounty", ...],
    platforms: ["facebook", "instagram", "twitter", "pinterest"]
  }
       |
[Step 10 — Log completion]
  Node: Odoo XMLRPC → create mail.activity
  Summary: "✅ Daily blog published: {title} | Shared to 4 platforms"
  Notify: WhatsApp to Sachin (optional)
```

## WORKFLOW WF-C: AI SHORT VIDEO CREATION PIPELINE
### (On-Demand for Any Brand — Produces TikTok/Reels/YouTube Shorts)

**Purpose:** Create a complete 30–60 second branded video from a topic idea  
**Trigger:** Webhook (manual trigger with brand + topic input)  
**Output:** Finished MP4 video → posted to TikTok, Instagram Reels, YouTube Shorts  
**Tools used:** Claude API + ElevenLabs + Pexels/Runway + Shotstack  

### Input Payload
```json
{
  "brand": "longislandcards",
  "topic": "Top 5 Pokémon cards to buy in 2026",
  "duration": 45,
  "style": "energetic | calm | informative | hype",
  "include_voiceover": true,
  "voice_id": "elevenlabs_voice_id_here"
}
```

### n8n Node Flow
```
[Webhook Trigger]
       |
[Step 1 — Research Trending Hooks]
  Node: HTTP Request → SerpAPI
  Search: "{topic} TikTok 2026 trending" + "viral hooks"
  Extract top 3 hook styles currently trending
       |
[Step 2 — Write Video Script (Claude API)]
  Node: HTTP Request → Anthropic API
  Prompt:
    "Write a {duration}-second TikTok/Reels script for {brand}.
     Topic: {topic}
     Hook (0–3s): Attention-grabbing opening line (no intro, start with the value)
     Body (4–40s): 3–5 punchy points, each max 2 sentences
     CTA (final 5s): 'Visit us at longislandcards.com or 605 Old Country Rd, Plainview NY'
     Style: {style}
     Format response as JSON:
     { hook, scenes: [{text, duration_sec, visual_cue}], cta, hashtags[] }"
  Output: structured script JSON
       |
[Step 3 — Generate AI Voiceover (ElevenLabs API)]
  Node: HTTP Request → ElevenLabs
  URL: https://api.elevenlabs.io/v1/text-to-speech/{voice_id}
  Body: {
    text: hook + " " + scenes.map(s=>s.text).join(" ") + " " + cta,
    model_id: "eleven_multilingual_v2",
    voice_settings: { stability: 0.5, similarity_boost: 0.8 }
  }
  Output: MP3 audio file → upload to temp storage, get audio_url
       |
[Step 4 — Source Video Clips (Pexels API)]
  For each scene visual_cue:
  Node: HTTP Request → Pexels Video API
  URL: https://api.pexels.com/videos/search?query={visual_cue}&per_page=3
  Select: first result with duration >= scene.duration_sec
  Collect: clips[] = [{ video_url, duration }]
       |
[Step 5 — Assemble Video (Shotstack API)]
  Node: HTTP Request → Shotstack
  URL: https://api.shotstack.io/v1/render
  Build timeline:
  {
    timeline: {
      soundtrack: { src: audio_url, effect: "fadeOut" },
      tracks: [
        {
          clips: scenes.map((scene, i) => ({
            asset: { type: "video", src: clips[i].video_url },
            start: cumulative_start_time,
            length: scene.duration_sec,
            effect: "zoomIn"
          }))
        },
        {
          clips: scenes.map(scene => ({
            asset: {
              type: "title",
              text: scene.text,
              style: "future",
              size: "medium",
              color: "#ffffff"
            },
            start: scene.start,
            length: scene.duration_sec
          }))
        },
        {
          // Brand watermark bottom-right
          clips: [{ asset: { type: "image", src: brand_logo_url },
                    position: "bottomRight", opacity: 0.8,
                    start: 0, length: total_duration }]
        }
      ]
    },
    output: { format: "mp4", resolution: "1080", fps: 30, aspectRatio: "9:16" }
  }
  Poll render status every 10 seconds until complete
  Output: finished_video_url
       |
[Step 6 — Download Video + Upload to Google Drive]
  Node: HTTP Request (GET) → download MP4
  Node: Google Drive → upload to /LongIslandVideos/{brand}/ folder
  Output: shareable drive link + local path
       |
[Step 7 — Send Preview for Approval]
  Node: HTTP Request → Twilio WhatsApp
  Message: "🎬 New video ready for {brand}\nTopic: {topic}\nPreview: {drive_link}\nReply YES to post or NO to discard"
       |
[Step 8 — Wait for Approval (Wait node — 24hr timeout)]
  Node: Wait → listen for webhook response from WhatsApp reply handler
       |
[IF approved = YES]
   └─[Step 9 — Trigger WF-A for Video Distribution]
       Payload: {
         brand, content_type: "video",
         text: hook + " " + cta,
         text_long: script_body,
         video_url: finished_video_url,
         image_url: video_thumbnail_url,
         hashtags: script.hashtags,
         platforms: ["tiktok", "instagram", "youtube"]
       }
```

```

       |
[Step 1 — Choose Content Type for Today]
  Node: Function Node
  Rotate through content types by day:
  Monday:    "product_spotlight"    — highlight a specific product
  Wednesday: "educational_tip"      — helpful tip related to brand
  Friday:    "promotion_offer"      — weekend deal or CTA
  Override: webhook input can specify type
       |
[Step 2 — Generate Caption + Hook (Claude API)]
  Node: HTTP Request → Anthropic API
  Prompt:
    "Create a social media post for {brand} (Long Island, NY).
     Content type: {content_type}
     Brand personality: {brand_personality}
     Write:
     - short_hook: 1 attention-grabbing first line (under 100 chars)
     - caption: engaging post body (under 300 chars, includes call to action)
     - hashtags: 10 relevant hashtags (mix of niche, location, trending)
     - image_prompt: detailed DALL-E 3 prompt to generate the hero image
     Format as JSON."
       |
[Step 3 — Generate Image (OpenAI DALL-E 3)]
  Node: HTTP Request → OpenAI
  URL: https://api.openai.com/v1/images/generations
  Body: {
    model: "dall-e-3",
    prompt: image_prompt + " Professional product photography style.
             Bright, vibrant. No text in image. High quality.",
    size: "1024x1024",    ← Square for Instagram
    quality: "standard",
    n: 1
  }
  Output: image_url
       |
[Step 4 — Resize for Each Platform (Shotstack or Sharp API)]
  Create 3 versions:
  - 1:1  (1080×1080) — Instagram feed, Facebook
  - 4:5  (1080×1350) — Instagram portrait (best reach)
  - 16:9 (1920×1080) — Twitter, LinkedIn, Pinterest
       |
[Step 5 — Add Brand Overlay (Shotstack)]
  Add to each image:
  - Brand logo (bottom corner, 15% opacity)
  - Website URL (bottom strip, semi-transparent)
  - Brand color accent (thin border or gradient)
       |
[Step 6 — Trigger WF-A Social Blast]
  Send all 3 image sizes + caption to WF-A
  WF-A selects correct image size per platform automatically
```
