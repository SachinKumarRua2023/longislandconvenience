## 🔧 How to Add Images to Homepage

### For Each Website, Do These Steps:

#### Step 1: Add Logo

**Via Odoo UI**:
```
1. Go to: Settings → Website → Branding
2. Upload: Logo image (200x80px)
3. Save
```

**Via Python Script**:
```python
import base64

# Read logo
with open('logo.png', 'rb') as f:
    image = base64.b64encode(f.read()).decode()

# Update all 14 websites
for website_id in [1, 18, 27, 29, 33, 36, 37, 38, 39, 40, 41, 42, 45, 46]:
    models.execute_kw(DB, uid, PASSWORD, 'website', 'write',
        [website_id],
        {'logo': image}
    )
```

#### Step 2: Add Products with Images

```
1. Go to: eCommerce → Products → Create
2. Enter: Product name, price, category
3. Upload: Product image
4. Assign: To website(s)
5. Publish: Check "Published" box
6. Save
```

#### Step 3: Add Category Images

```
1. Go to: eCommerce → Categories
2. Open: Category
3. Upload: Category icon/image
4. Save
```

## 🚀 Quick Start: Add Image to Website 1

### Option A: Via UI (Manual)

```
1. Login: https://country-cove-inc.odoo.com/
2. Go to: Settings → Website → Branding → Logo
3. Upload: logo.png
4. Save
5. Done! Logo appears on website
```

### Option B: Via Python (Fast)

```python
import xmlrpc.client
import base64

URL = "https://country-cove-inc.odoo.com"
DB = "country-cove-inc"
EMAIL = "countrycoveinc@gmail.com"
PASSWORD = "M@nhattan1234"

common = xmlrpc.client.ServerProxy(f"{URL}/xmlrpc/2/common")
uid = common.authenticate(DB, EMAIL, PASSWORD, {})
models = xmlrpc.client.ServerProxy(f"{URL}/xmlrpc/2/object")

# Read image
with open('logo.png', 'rb') as f:
    image = base64.b64encode(f.read()).decode()

# Update Website 1
models.execute_kw(DB, uid, PASSWORD, 'website', 'write',
    [1],
    {'logo': image}
)

print("✓ Logo uploaded to Website 1")
```
