# Universal — n8n Workflow & Automation Tools
Scripts for managing n8n workflows, reel creation, and automation patches.

## Scripts

| Script | What It Does |
|--------|-------------|
| `cvp.py` | Sync n8n workflow code via MCP server |
| `patch_prompt.py` | Patch AI prompt in n8n workflow node |
| `patch_brief.py` | Patch brief/summary in workflow |
| `patch_brief_source.py` | Patch source data for brief |
| `patch_fetch_fix.py` | Fix HTTP fetch node in workflow |
| `patch_final_fixes.py` | Final workflow fixes |
| `patch_form.py` | Patch form submission handling |
| `patch_html_extract.py` | Patch HTML extraction node |
| `patch_scraper_fix.py` | Fix scraper workflow node |
| `patch_uid_fix.py` | Fix user ID in workflow auth |
| `fix_jsonbody.py` | Fix JSON body in HTTP Request nodes |
| `fix_shotstack_body.py` | Fix Shotstack API request body |
| `fix_reel_creator.py` | Fix reel/video creation workflow |
| `get_reel_code.py` | Get reel creation code |
| `inspect_reel_detail.py` | Inspect reel details |
| `inspect_reels.py` | List all reels |
| `capitalone_statements.py` | Download Capital One statements via Chrome |
| `fix_free_blogger.py` | Fix free blog platform integration |
