**Tech Stack:**
- Backend: Python/Django, Node.js/Express.js
- Frontend: React, Next.js
- Database: PostgreSQL, Redis
- AI Integration: Claude API, GPT-4 API
- Mobile: React Native

**Deliverables for Hiren:**
1. Site 5 — Game/Gambling Cards (complete custom build)
2. Site 6 — Sports Cards Marketplace (complete custom build)
3. Mobile App — iOS + Android
4. Backend APIs for all Odoo integrations
5. RAG system integrations (#2-5)

**Key Processes:**
- Git-based version control (GitHub)
- Code review before merge
- Claude/GPT AI-assisted development for velocity
- Weekly demo to Sachin + Hiren
