================================================================================
                       TROUBLESHOOTING
================================================================================

PROBLEM: GitHub Pages says "Not Found"
SOLUTION: Wait 5 minutes after clicking Save in Settings

PROBLEM: Images not showing in Odoo
SOLUTION:
  1. Check GitHub Pages is enabled (green checkmark)
  2. Hard refresh Odoo: Ctrl+Shift+R
  3. Check iframe code is pasted exactly as shown above

PROBLEM: Styling looks wrong
SOLUTION: Hard refresh browser (Ctrl+Shift+R)

PROBLEM: Mobile not responsive
SOLUTION: Check browser width is less than 768px
